# NexaGram branding

Кидай сюда исходники иконок. Я сам нарежу их по размерам и разложу в mipmap-папки.

| Файл | Размер | Что это |
|---|---|---|
| `icon_foreground.png` | 432×432, прозрачный фон | Сам значок. Всё важное держать в центральном круге диаметром ~264 px, края Android обрезает под форму (круг, квадрат и т.д.) |
| `icon_background.png` | 432×432 | Фон под значком (или просто напиши цвет) |
| `icon_monochrome.png` | 432×432, белый силуэт на прозрачном | Для «тематических» иконок Android 13+ |
| `icon_notification.png` | 96×96, белый силуэт на прозрачном | Значок в шторке уведомлений |
| `play_icon.png` | 512×512, без прозрачности | Иконка для страницы в Google Play |
| `feature_graphic.png` | 1024×500 | Баннер для Google Play (можно позже) |

Лучше всего прислать один SVG или PNG 1024×1024 со значком отдельно от фона: остальное сделаю из него.
